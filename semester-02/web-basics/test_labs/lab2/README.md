# Лабораторная №2 · Сбор и обработка данных веб-формы

> **Основы профессиональной деятельности** · 2-й семестр · `ITMO / Нейротехнологии и программирование`

**Технологии:** HTML

## Задача

Практическая реализация по теме «Сбор и обработка данных веб-формы». Полный текст задания в переданных файлах не обнаружен.

## Основные файлы

- [hard_color.html](./hard_color.html)
- [hard_sound.html](./hard_sound.html)
- [simp_color.html](./simp_color.html)
- [simp_sound.html](./simp_sound.html)
- [visual.html](./visual.html)

## Как запустить

Для статического HTML/CSS/JavaScript откройте `index.html` в браузере или запустите локальный HTTP-сервер; для PHP потребуется веб-сервер с поддержкой PHP.

## Статус документации

Описание приведено по доступным материалам и структуре кода. Если оригинальный текст задания не сохранился, формулировка выше является кратким описанием реализации, а не официальным ТЗ.
