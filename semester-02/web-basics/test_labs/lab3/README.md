## Задача

Практическая реализация по теме «Интерактивное веб-приложение». Полный текст задания в переданных файлах не обнаружен.

## Основные файлы

- [hard_circle.html](./hard_circle.html)
- [hard_circle.js](./hard_circle.js)
- [simple_circle.html](./simple_circle.html)

## Как запустить

Для статического HTML/CSS/JavaScript откройте `index.html` в браузере или запустите локальный HTTP-сервер; для PHP потребуется веб-сервер с поддержкой PHP.
