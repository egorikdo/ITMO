# Лабораторная №5 · Тестирование веб-сценариев

> **Основы профессиональной деятельности** · 2-й семестр · `ITMO / Нейротехнологии и программирование`

**Технологии:** HTML

## Задача

Практическая реализация по теме «Тестирование веб-сценариев». Полный текст задания в переданных файлах не обнаружен.

## Основные файлы

- [attention.html](./attention.html)
- [memory.html](./memory.html)
- [mind.html](./mind.html)

## Как запустить

Для статического HTML/CSS/JavaScript откройте `index.html` в браузере или запустите локальный HTTP-сервер; для PHP потребуется веб-сервер с поддержкой PHP.
