## Как запустить

Откройте директорию проекта через **Unity Hub**, выбрав совместимую версию Unity из `ProjectSettings/ProjectVersion.txt`. Сцены находятся в `Assets/`. Внешние пакеты или не включённые в архив медиа могут потребоваться дополнительно.
