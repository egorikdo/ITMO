# Архитектура компьютера

> **4-й семестр** · Assembler · симуляция процессора

Исходные материалы представлены в виде программ, ноутбуков и конфигураций. **24 файлов** (без README).

## Содержание

- [Лабораторная №3 · Симуляция архитектуры компьютера](./lab3/README.md)

## Технологии

`Python` · `Assembler`

## Запуск

Понадобятся компилятор **GCC/Clang**, `make` и инструменты, указанные в коде. Для xv6 также нужен **QEMU**. Команды сборки зависят от конкретной версии проекта.

## Важные замечания

- Сборка и работа на всех средах **не подтверждены**: для ряда заданий требуются внешние датасеты, сервисы или отдельные учебные компоненты.
- Отчёты, PDF, презентации и сгенерированные файлы сборки исключены из подборки.
- Лицензионные файлы сторонних компонентов сохранены.
