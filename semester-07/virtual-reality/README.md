# Разработка приложений виртуальной реальности

> **7-й семестр** · Unity · C# · VR

## Содержание

- Исходный проект и необходимые файлы находятся в этой папке.

## Технологии

`C#` · `Unity`

## Запуск

Откройте директорию проекта через **Unity Hub**, выбрав совместимую версию Unity из `ProjectSettings/ProjectVersion.txt`. Сцены находятся в `Assets/`. Внешние пакеты или не включённые в архив медиа могут потребоваться дополнительно.

## Важные замечания

- Сборка и работа на всех средах **не подтверждены**: для ряда заданий требуются внешние датасеты, сервисы или отдельные учебные компоненты.
- Отчёты, PDF, презентации и сгенерированные файлы сборки исключены из подборки.
- Лицензионные файлы сторонних компонентов сохранены.
