# Разработка веб-приложений

> **5-й семестр** · TypeScript · Next.js · Node.js

Исходные материалы представлены в виде программ, ноутбуков и конфигураций. **194 файлов** (без README).

## Содержание

- **`backend/`** — 15 файлов кода и конфигурации
- **`frontend/`** — 177 файлов кода и конфигурации

## Технологии

`TypeScript` · `React/TSX` · `JavaScript` · `CSS`

## Запуск

Используйте **Node.js** и пакетный менеджер из проекта. В директории с `package.json` выполните `npm install`, затем посмотрите доступные скрипты командой `npm run`.

## Важные замечания

- Сборка и работа на всех средах **не подтверждены**: для ряда заданий требуются внешние датасеты, сервисы или отдельные учебные компоненты.
- Отчёты, PDF, презентации и сгенерированные файлы сборки исключены из подборки.
- Лицензионные файлы сторонних компонентов сохранены.
