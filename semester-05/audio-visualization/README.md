# Мультимедиа: визуализация аудио

> **5-й семестр** · JavaScript · Web Audio

## Содержание

- **`css/`** — 1 файлов кода и конфигурации
- **`js/`** — 3 файлов кода и конфигурации

## Технологии

`JavaScript` · `HTML` · `CSS`

## Запуск

Для статического HTML/CSS/JavaScript откройте `index.html` в браузере или запустите локальный HTTP-сервер; для PHP потребуется веб-сервер с поддержкой PHP.

## Важные замечания

- Сборка и работа на всех средах **не подтверждены**: для ряда заданий требуются внешние датасеты, сервисы или отдельные учебные компоненты.
- Отчёты, PDF, презентации и сгенерированные файлы сборки исключены из подборки.
- Лицензионные файлы сторонних компонентов сохранены.
