# ITMO · Neurotech Labs

**Лабораторные и учебные программные проекты · 1–7-й семестры**

Архив программных практик по направлению «Нейротехнологии и программирование» Университета ИТМО: от Java и C до машинного обучения, обработки ЭЭГ и Unity. Включены **27 дисциплин**; факультативы и 8-й семестр исключены.

> **О происхождении:** исходный код и решения лабораторных взяты из открытых репозиториев [CandyGoose](https://github.com/CandyGoose/ITMO_Software_engineering) **с разрешения автора**. Эта публикация — переработанная подборка и документация, а не заявление о самостоятельном выполнении всех исходных работ составителем.

## Как пользоваться архивом

1. Выберите семестр и дисциплину в таблице выше.
2. Откройте README работы: там описаны доступная постановка задачи, исходники и особенности запуска.
3. Установите зависимости конкретной работы и проверьте необходимые данные/ассеты. **Общего универсального запуска нет:** лабораторные написаны на разных языках и для разных сред.

Большинство Jupyter-ноутбуков не содержат сохранённых выводов; для воспроизведения нужны Python-пакеты и иногда внешние датасеты. Проекты Android и Unity требуют совместимых версий IDE, SDK и пакетов. Часть Unity-ассетов и моделей отсутствовала уже в предыдущей отфильтрованной сборке.
